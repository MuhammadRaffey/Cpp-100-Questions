# Final Exam Preparation: 100 Scenario-Based Questions

## 1. Loops (Do, While, For)

1. **Scenario**: A vending machine gives a discount if a customer buys more than five items. Write a program using a `while` loop that calculates the total cost based on user input (item prices) and applies the discount if applicable.
2. **Scenario**: A school organizes a quiz competition where each team answers questions until they decide to stop. Write a `do-while` loop program that continues taking inputs for correct answers and calculates the score until the team enters "STOP."
3. **Scenario**: A bank wants to calculate the compound interest on deposits for the next 10 years. Write a `for` loop program to display the balance year by year.
4. **Scenario**: An online store tracks sales data for each day of the week. Write a nested loop to calculate the total weekly sales and display the day with the highest sales.
5. **Scenario**: A manufacturing plant produces widgets in cycles. Write a program that calculates the total number of widgets produced after a specific number of cycles using a `for` loop.
6. **Scenario**: A health tracker app records the number of steps a user takes daily. Write a program to find the average number of steps for a week using a `while` loop.
7. **Scenario**: A farmer tracks rainfall over multiple months. Use a nested loop to calculate the total rainfall for each month and determine which month had the highest rainfall.
8. **Scenario**: A fitness app calculates calories burned during multiple workouts. Write a program that uses a loop to total the calories burned in a week.
9. **Scenario**: An amusement park tracks the number of visitors in each hour of the day. Write a program using a `for` loop to calculate the total number of visitors in a day.
10. **Scenario**: A student wants to calculate the sum of all prime numbers less than 100. Write a program using a nested loop to achieve this.
